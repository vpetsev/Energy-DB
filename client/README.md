# Energy DB client

Requires Node.js 22. From this directory:

```sh
npm ci
npm start
```

Open http://127.0.0.1:5173. The dev server binds to localhost.

- `npm run build` creates a production bundle in `dist/`.
- `npm run preview` serves that bundle locally.

See [RUNNING.md](../RUNNING.md) for the macOS launcher, data sampling behavior, and restored map features.
